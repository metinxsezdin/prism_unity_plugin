# Prism MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Unity-independent stdio MCP server (`prism`) that lets Claude query, organise and manage versions in a Prism 2.1.2.1 project without ever opening a window, plus a one-click installer for the team.

**Architecture:** `PrismMcp/server.py` runs on Prism's own Python, speaks MCP (JSON-RPC 2.0, newline-delimited stdio) with a standard-library implementation, and lazily boots `PrismCore` with `noUI`/`silent`. Every tool call runs inside the existing `unity_bridge.headless.headless(core)` guard so Prism dialogs become errors. Mutating tools use a two-step preview → `confirm` token flow. Product/version listings reuse `unity_bridge.commands.PrismCommands` so the shapes match the Unity-side `prism_*` tools.

**Tech Stack:** Python 3.13 (Prism's bundled `Python313`), Prism 2.1.2.1 Python API, `unittest`, PowerShell 5.1 + `.bat` for the installer.

**Spec:** [docs/superpowers/specs/2026-11-12-prism-mcp-design.md](../specs/2026-11-12-prism-mcp-design.md)

## Global Constraints

- Team Prism version: `v2.1.2.1` (compare against `core.version`). One constant: `prism_mcp.session.TEAM_PRISM_VERSION`. No compatibility layer.
- Python: `<PrismRoot>\Python313\python.exe`; no third-party packages; `PRISM_ROOT` env var, default `C:\Program Files\Prism2`.
- No window, ever: every Prism call inside `headless(core)`; `QT_QPA_PLATFORM=offscreen` set before Qt is imported; `PrismCore.create(app="Standalone", prismArgs=["noUI", "silent"])`.
- stdout carries only MCP JSON-RPC lines; everything else (Prism logs, prints, C-level writes) goes to stderr.
- No Unity dependency: from `Unity/Scripts/unity_bridge` only `headless`, `protocol.BridgeError`, `projects.pin_project` and `commands.PrismCommands` (constructed with `unity=None`) may be used.
- Error codes: `needs_input`, `needs_confirmation`, `source_unavailable`, `prism_unavailable`, `bad_args`, `timeout`, `internal` (the `BridgeError` set; never `unity_busy`/`missing_package`).
- Entity shape: `{"type":"asset","asset_path":"Props/Lotus"}`, `{"type":"shot","sequence":"sq01","shot":"sh010"}` (+`episode` when the project uses episodes).
- Tool result text = JSON `{"ok": true, "project": {"name","path"}, "result": ...}` or `{"ok": false, "project": ..., "error": {"code","message","details"}}`; MCP `isError` is true for the second.
- Confirmation description sentence, verbatim in every mutating tool: `Never confirm on your own. Show the user details.summary and details.changes and ask; call again with confirm only after the user says yes.`
- Trash folder: `<projectPath>/00_Pipeline/Trash/<YYYYMMDD-HHMMSS>_<sequence>-<shot>/`.
- Audit log: `%USERPROFILE%\Documents\Prism2\PrismMcp.log`, one JSON object per line.
- List tools take `limit` (default 200) and return `{"items": [...], "truncated": bool}`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Do not push.

## Review Focus

1. **Offline project drive** (the team project lives on `M:`): `list_projects` marks it `reachable: false`; any tool against an unreachable project answers `source_unavailable` quickly instead of hanging or raising `internal`. Pinned in Task 2 (`test_unreachable_project_is_source_unavailable`).
2. **Turkish names through stdio** (`Props/Çay Bardağı`): requests and answers round-trip as UTF-8 on Windows regardless of the console code page. Pinned in Task 1 (`test_utf8_round_trip`) and Task 9 (`test_subprocess_turkish_entity`).
3. **Prism asking a question mid-operation** (invalid asset name, existing folder): the tool answers `needs_input`/`internal` and nothing is left half-created. Pinned in Task 5 (`test_invalid_asset_name_is_bad_args_not_dialog`).
4. **Someone else changes the same thing between preview and confirm**: the old token is refused with a fresh `needs_confirmation`. Pinned in Task 2 (`test_stale_token_is_refused`) and Task 6 (`test_set_master_token_tracks_current_master`).
5. **A new teammate with no Prism user name**: `status` and `server.py --check` say exactly what to do, no dialog. Pinned in Task 2 (`test_status_without_user_is_needs_input`) and Task 9 (`test_check_reports_missing_user`).
